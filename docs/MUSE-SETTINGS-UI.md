# Muse 设置界面

基于此前移植版本重新整理，仅替换设置和设备信息的界面。布局参考
`codex/muse-esp-idf-research` 的 `muse_settings_ui.c`，输入按键复用
`muse_keypad.c/.h`（Meta，Apache-2.0；保留原许可声明）。

设置使用紫色卡片、独立子页、滑条、右滑返回及圆屏按键。删除配网、
蓝牙、音量和设备页的说明段落，只展示字段、数值和必要状态。
不包含 Muse 账号/服务器选项。小智仍通过 main 的配置接口保存。

本次没有移植网络配置存储、多网络选择、设备后台任务、麦克风监听、
睡眠/关机或电池耗电统计；保持回退后的 main 服务和配额同步实现。
电池页直接展示现有采样，区分估算电量和电量计 SOC。

`scripts/preview-ui.ps1` 编译实际设置界面，检查密码校验、开放网络、
连接忙、确认过期、蓝牙开关、音量保存、输入取消和 30 次页面生命周期。
输出 `.cache/ui-preview/settings-round.png`。固件使用 `scripts/build.ps1` 构建。
这些检查不代表 Wi-Fi、蓝牙或配额已经完成实机验收。
