## 内存、网络及电池调整

- 普通分配优先 PSRAM，MbedTLS 明确使用 PSRAM；LCD 双 DMA 缓冲与内部保留区沿用 0.2.1 修正。
- 网络测试分开记录 DNS、有效时间、TLS 证书验证、HTTP 状态、socket/TLS 错误与耗时；读取 HTTPS 响应头，避免下载整页正文。
