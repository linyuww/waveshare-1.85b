## 内存、网络及电池调整

- 普通分配优先 PSRAM，MbedTLS 明确使用 PSRAM；LCD 双 DMA 缓冲与内部保留区沿用 0.2.1 修正。
- 网络测试分开记录 DNS、有效时间、TLS 证书验证、HTTP 状态、socket/TLS 错误与耗时；读取 HTTPS 响应头，避免下载整页正文。
- 初次联网且校时完成后自动测试一次，后续可在网络应用手动测试。
- 电池每 5 秒读取，服务持有原始数据并向 GUI 发布锁保护快照。BLE 启动失败不再停止电池更新；失败采样标记为旧数据。
- 设备信息含估算电量和原始 SOC、电压、实测/平均电流、平均功率、温度/芯片温度、剩余/满充/设计容量、健康度、循环次数、预计时间、建议充电参数及状态寄存器。请求值与测量值分开标注，不可用时间显示 `--`。

## USB 实机验证

- `logs/flash-0.2.2-layout-20261003.log`：bootloader、分区表、应用均通过设备端哈希校验，烧录退出码 0；保留 NVS。
- `logs/boot-0.2.2-layout-20261003.log`：连续观察 75 秒，版本 0.2.2，启动 ELF SHA 前缀 `8d752d2ab` 与最终二进制匹配。
- 原有 Wi-Fi 自动连接并获得 IP，SNTP 校时后在后台执行 HTTPS 检查。
- `Certificate validated`；HTTPS 返回 `ESP_OK / HTTP 302`，耗时 884 ms，TLS/mbedTLS/证书 flags/socket 错误均为 0。302 是服务端重定向响应，足以证明 DNS、连接、TLS 和 HTTP 响应头读取成功；此测试不跟随重定向或下载全文。
- BLE 使用保留的配对自动重连、MTU 517；RGB、线程及设备状态 RPC 收发成功，所有记录的发送 `failed=0`，GATT 确认 `status=0`。
- 启动约 62.6 秒：内部可用 RAM 23,803 字节，最大 DMA 空闲块 15,360 字节，PSRAM 可用 2,536,408 字节。
- 观察期间未报告 ESP_ERR_NO_MEM、panic、看门狗、DMA 分配失败或非预期重启。
